# UooDoo Project Documentation

This file summarizes the project layout and explains how the different parts work together.

## Project Overview

UooDoo is a desktop-based video library system inspired by the proposal in the attached PDF. The project currently includes:

- a console-based version
- a native Qt desktop application
- a simple test suite for the core library logic

## Main Files

### Root Files
 - README.md: overall project guide
 - ROOT_README.md: this file, which explains the project structure
 - CMakeLists.txt: build configuration for the project
 - uoodoo_qt.cpp: native Qt-based graphical UI

## Integrated Player

The Qt UI now includes an internal `VideoPlayer` component (see `src/VideoPlayer.h` and `src/VideoPlayer.cpp`) which uses `QMediaPlayer` and `QVideoWidget`. The CMake configuration was updated to require `Qt6::Multimedia` and `Qt6::MultimediaWidgets` in addition to `Qt6::Widgets`.

### src/
Contains the core library and logic for video management.

### tests/
Contains automated tests for the library manager.

### build/
Stores compiled binaries and build output generated by CMake.

## Working Mechanism

1. The application loads a list of videos from saved metadata.
2. Users can add or remove videos through the interface.
3. Each video entry contains its filename, file path, and favorite status.
4. The library manager saves changes so the data persists across runs.
5. The GUI layers present the library in a visual form for easier interaction.

## How to Use

- Run the console app from the build folder.
- Run the Qt executable for a more polished desktop experience.

## Notes

The project is structured to separate logic, tests, and interface layers. This makes future improvements easier and keeps the implementation modular.
